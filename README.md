# 🚀 PyQt Postman Pro

Аналог Postman на Python с графическим интерфейсом PyQt5.  
Отправляй HTTP-запросы, работай с коллекциями, настраивай каждую мелочь под себя.

## ✨ Возможности

- 📬 **Отправка запросов** – GET, POST, PUT, DELETE, PATCH с параметрами, заголовками и телом (raw JSON/текст).
- 📑 **Вкладки и окна** – каждый запрос в отдельной вкладке; вкладки можно **отсоединять в отдельные окна** и возвращать обратно.
- 🎨 **Гибкая тема** – полная кастомизация цветов через встроенный редактор, настройки сохраняются.
- 📁 **Коллекции** – дерево запросов слева, по клику создаётся новая вкладка с предустановленными данными.
- 🔍 **Масштабирование** – Ctrl + колесо мыши или пункты меню меняют размер интерфейса.
- ⚡ **Асинхронные запросы** – интерфейс не зависает при отправке.
- 💾 **Локальное сохранение темы** – файл `postman_theme.json` с вашими цветами.
