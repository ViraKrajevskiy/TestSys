# 🚀 Быстрый Старт (5 минут)

## Что это

**TestSys** — это desktop приложение на Python которое работает как Postman + интегрированное управление пользователями через собственный API.

## Пререквизиты

- ✅ Python 3.10+
- ✅ PostgreSQL 12+ (или WSL2 на Windows)
- ✅ pip (обычно идёт с Python)

## Запуск

### Windows

```bash
# Двойной клик по run.bat
# ИЛИ в PowerShell:
.\run.bat
```

### Linux/Mac

```bash
chmod +x run.sh
./run.sh
```

### Ручной запуск (если скрипты не работают)

**Терминал 1:**
```bash
cd testsys_backend
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

**Терминал 2:**
```bash
cd Backend
pip install -r requirements.txt
python main.py
```

## Первый запуск ✨

1. **Запустите скрипт** (`run.bat` или `run.sh`)
2. **Откроется окно приложения** — это TestSys (Postman-like интерфейс)
3. **Нажмите кнопку 👥** в верхней панели (navbar)
4. **Загрузятся пользователи** из БД
5. **Создайте пользователя** — нажмите "Новый пользователь"

## Основные возможности

### 1️⃣ Postman режим (как обычно)

- Создавать новые вкладки (Ctrl+T)
- Вводить любой URL
- Выбирать метод (GET, POST, PUT, DELETE, PATCH)
- Добавлять параметры и заголовки
- Нажимать Send → видеть ответ

### 2️⃣ Управление пользователями 👥

**Кнопка в верхней панели → Вкладка Users**

**Таблица:**
- Все пользователи из БД
- Кнопка "Обновить" для перезагрузки
- Кнопка карандаша — редактирование
- Кнопка корзины — удаление

**Создание:**
- "Новый пользователь" → открывается форма
- Заполняете: Имя*, Email* (остальное опционально)
- "Создать" → появляется в таблице

## Примеры

### Создать пользователя

1. Нажмите 👥 → вкладка Users
2. Нажмите "Новый пользователь"
3. Заполните:
   - Имя: `Alice Smith`
   - Email: `alice@example.com`
   - Компания: `ONESEC`
4. Нажмите "Создать" ✅

### Отредактировать

1. В таблице нажмите карандаш у пользователя
2. Измените данные
3. Нажмите "Сохранить" ✅

### Удалить

1. В таблице нажмите корзину
2. Подтвердите ✅

### Тестировать API напрямую

```
http://127.0.0.1:8000/docs
```

Откроется Swagger UI где можно тестировать все эндпоинты.

## Решение проблем

### "Failed to connect to API"
- ✅ Проверьте что в терминале 1 написано `Application startup complete.`
- ✅ Может быть долгий первый запуск (создание venv)

### "Database connection failed"
- ✅ PostgreSQL запущен? (`psql -U postgres` в терминале)
- ✅ Правильный пароль в `testsys_backend/database.py`?

### Приложение вообще не запускается
- ✅ Python установлен? (`python --version`)
- ✅ В проекте есть папки `Backend` и `testsys_backend`?
- ✅ Запустите скрипт из корня проекта

### Кнопка 👥 не видна
- ✅ Закройте приложение и откройте снова
- ✅ Очистите кэш браузера (F5 на странице)
